# Security policy

## Reporting a vulnerability

Report a suspected vulnerability privately, by email to the CMS ISPG Zero Trust Team at [ISPGZeroTrust@cms.hhs.gov](mailto:ISPGZeroTrust@cms.hhs.gov). Do not open a public issue, pull request or discussion about it.

Include what is affected (a file, an endpoint, a commit), how to reproduce it, and the impact you expect.

## Scope

This repository's application code, its infrastructure definitions and its container build. A vulnerability in a dependency is best reported to that dependency's maintainers; tell us as well if this repository uses it in a way that is exploitable.

## Supported versions

Fixes are made on the default branch.
